# Módulo 01 — Fundamentos de Hardware

## Objetivo

Desenvolver conhecimentos práticos sobre componentes de hardware, identificação de problemas e procedimentos iniciais de diagnóstico utilizados no suporte técnico N1.

## Conteúdos estudados

- Processador (CPU)
- Memória RAM
- SSD e HD
- Placa-mãe
- Placa de vídeo (GPU)
- BIOS e UEFI
- POST e diagnóstico inicial
- Temperatura e Thermal Throttling

## Laboratórios realizados

1. Inventário de hardware.
2. Identificação de componentes utilizando PowerShell.
3. Verificação de informações de armazenamento.
4. Diagnóstico de memória RAM com Windows Memory Diagnostic.
5. Monitoramento de CPU e GPU com HWiNFO.

## Simulação de atendimento

**Chamado TI-001 — Lentidão durante utilização do Excel e navegador.**

Investigação de consumo de recursos, diagnóstico de memória, otimização básica do Windows e encaminhamento para avaliação de possível expansão de RAM.

## Ferramentas utilizadas

- Windows 11
- PowerShell
- Gerenciador de Tarefas
- Visualizador de Eventos
- Windows Memory Diagnostic
- HWiNFO

## Competências desenvolvidas

- Identificação de componentes de hardware.
- Diagnóstico inicial de problemas.
- Monitoramento de recursos.
- Troubleshooting.
- Comunicação com usuários.
- Documentação de chamados.
